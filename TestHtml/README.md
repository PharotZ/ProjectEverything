# TestHtml

Ce dossier regroupe des exemples et ressources pour un projet web statique de portfolio.
Il s'agissait de mon tout premier projet, il est par conséquent assez rudimentaire comme je n'avais pas d'idée générale de quoi faire et que j'apprenais le B.A.-BA du code.
De plus, ce code fut assez vite laissé de côté pour travailler puis pour mes études.

## Contenu principal

 **index.html** : page d’accueil du projet, point d’entrée principal.
 **aesthetics.html** : exemples et inspirations sur mon esthétique visuelle.
 **architecture.html** : ressources et illustrations sur l’architecture.
 **clothes.html** : présentation de marques et styles vestimentaires.
 **music.html** : section dédiée à la musique et à ses influences.
 **test.html** : page de test pour expérimenter des scripts et des styles. La volonté était de créer des styles personnalisés à 100% afin de montrer les possibilités d'affichages.

 ## P5js

 La librairie p5js est une librairie dédiée aux scripts permettant l'affichage d'animations. Le but était de trouver un côté artistique a la programmation.

 Il suffit d'accéder à la page index.html de ce dossier pour observer la première animation.
